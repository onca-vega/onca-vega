#### Onca Vega Press

`Our brand's product` · Publishing imprint · Platform

A Mexican imprint, formed by a team, that publishes cosmic horror, science fiction, supernatural terror and dark fantasy — starting with _Fisura Interdimensional_ — and offers editorial services to independent authors. The platform behind it includes a catalogue of books and authors, a community of independent writers, and an admin panel with user roles, authentication and its own API.

**Stack:** Astro · Vue 3 · TypeScript · Tailwind CSS · NestJS · Prisma<br>
**Visit:** [sello-editorial.onca-vega.com](https://sello-editorial.onca-vega.com/en/)

#### Onca Vega Sello Editorial

`Producto de nuestra marca` · Sello editorial · Plataforma

Un sello mexicano formado por un equipo que publica horror cósmico, ciencia ficción, terror sobrenatural y fantasía oscura —empezando por _Fisura Interdimensional_— y que ofrece servicios editoriales a autores independientes. La plataforma detrás incluye un catálogo de libros y autores, una comunidad de escritores independientes y un panel de administración con roles de usuario, autenticación y API propia.

**Stack:** Astro · Vue 3 · TypeScript · Tailwind CSS · NestJS · Prisma<br>
**Visitar:** [sello-editorial.onca-vega.com](https://sello-editorial.onca-vega.com/)
